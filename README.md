# Liangze Robert Ke — personal site

Static site for GitHub Pages. No build step.

    index.html          all documents (Domus, Academica, Biometrika, Genomica, Statistica, Litterae, Regeneratio, Salutant)
    assets/style.css    layout, Red Doc> columns, white/black themes
    assets/main.js      page switching (#hash), theme toggle, [ ] keys
    assets/fig/         Figure 1 of each paper

Deploy: push the contents of this folder to a repo named `<username>.github.io`,
then Settings → Pages → Deploy from branch `main` / root.
